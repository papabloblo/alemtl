ALE-MTL Documentation
=====================

ALE-MTL is a Python/PyTorch toolkit for building, training, explaining, and
comparing multi-task learning models. The package centers on a workflow where
task-specific behavior is summarized with Accumulated Local Effects (ALE)
profiles and task relationships are estimated from curve similarity.

The documentation is written for two audiences:

* users who want to run the examples, compute ALE profiles, and train models;
* reviewers and maintainers who need reproducible installation, API, citation,
  and SoftwareX publication information.
